# E-Shop Brasil
## Sistema de gerenciamento de clientes e pedidos

### 1. Finalidade do projeto

O projeto E-Shop Brasil tem como finalidade desenvolver um sistema de gerenciamento de clientes e pedidos para uma empresa de comércio eletrônico.

A aplicação utiliza Python, Streamlit e MongoDB para cadastrar, consultar, atualizar e excluir informações de clientes e pedidos.

O sistema busca facilitar a organização dos dados, melhorar o acesso às informações e apoiar a tomada de decisões da empresa.

### 2. Tecnologias utilizadas

- Python: linguagem de programação utilizada no desenvolvimento.
- Streamlit: criação da interface do sistema.
- MongoDB: banco de dados NoSQL para armazenamento das informações.
- PyMongo: conexão entre Python e MongoDB.
- Pandas: organização e apresentação dos dados.
- Docker: configuração para empacotamento e execução do projeto.

### 3. Funcionalidades

- Cadastro de clientes.
- Cadastro de pedidos.
- Consulta de clientes e pedidos.
- Edição de informações.
- Exclusão de registros.
- Relatórios e visualização de dados.

### 4. Banco de dados

O projeto utiliza o MongoDB, um banco de dados NoSQL que armazena informações em documentos.

Foram utilizadas as coleções clientes e pedidos para organizar os dados da aplicação.

### 5. Segurança

O arquivo .env armazena a configuração de conexão com o banco de dados. Ele não deve ser compartilhado publicamente.

### 6. Conclusão

O desenvolvimento do E-Shop Brasil demonstra como tecnologias de banco de dados e programação podem contribuir para a organização e o gerenciamento das informações de uma empresa de comércio eletrônico.

### 7. Objetivos do projeto

**Objetivo geral**

Desenvolver uma aplicação para gerenciar clientes e pedidos de uma empresa de comércio eletrônico, utilizando tecnologias de banco de dados e programação.

**Objetivos específicos**

- Organizar os dados dos clientes e pedidos.
- Permitir o cadastro, a consulta, a edição e a exclusão de informações.
- Demonstrar o uso do banco de dados MongoDB.
- Gerar relatórios para acompanhar os pedidos e valores das vendas.
- Apresentar como a tecnologia pode melhorar a gestão da empresa.

### 8. Tecnologias utilizadas

- **Python:** linguagem utilizada para desenvolver a aplicação.
- **Streamlit:** ferramenta utilizada para criar a interface visual do sistema.
- **MongoDB:** banco de dados NoSQL utilizado para armazenar clientes e pedidos.
- **PyMongo:** biblioteca responsável pela comunicação entre Python e MongoDB.
- **Pandas:** biblioteca utilizada para organizar e apresentar dados.
- **Docker:** arquivos de configuração preparados para permitir a execução da aplicação em contêineres.

### 9. Resultados esperados

Com o desenvolvimento do sistema E-Shop Brasil, espera-se:

- Melhorar a organização das informações dos clientes.
- Facilitar o acompanhamento dos pedidos.
- Reduzir erros no cadastro e na consulta de dados.
- Gerar relatórios que auxiliem na tomada de decisões.
- Demonstrar a importância do banco de dados NoSQL no comércio eletrônico.
- Mostrar como as tecnologias digitais podem contribuir para a eficiência da empresa.

### 10. Considerações finais

O desenvolvimento deste projeto permitiu aplicar conhecimentos de programação, banco de dados e análise de informações em uma situação prática de comércio eletrônico.

A aplicação demonstra como o Python, o Streamlit e o MongoDB podem trabalhar juntos para facilitar o gerenciamento de clientes e pedidos.

Conclui-se que o uso adequado da tecnologia contribui para melhorar a organização, a produtividade e a tomada de decisões em uma empresa.
