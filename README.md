# E-Shop Brasil
## Sistema de gerenciamento de clientes e pedidos

### 1. Finalidade do projeto

O projeto E-Shop Brasil tem como finalidade desenvolver um sistema de gerenciamento de clientes e pedidos para uma empresa de comércio eletrônico.

A aplicação utiliza Python, Streamlit e MongoDB para cadastrar, consultar, atualizar e excluir informações de clientes e pedidos.

O sistema busca facilitar a organização dos dados, melhorar o acesso às informações e apoiar a tomada de decisões da empresa.

### 2. Tecnologias utilizadas

- Python: linguagem de programação utilizada no desenvolvimento.
- Streamlit: criação da interface do sistema.
- MongoDB: banco de dados NoSQL para armazenamento das informações.
- PyMongo: conexão entre Python e MongoDB.
- Pandas: organização e apresentação dos dados.
- Docker: configuração para empacotamento e execução do projeto.

### 3. Funcionalidades

- Cadastro de clientes.
- Cadastro de pedidos.
- Consulta de clientes e pedidos.
- Edição de informações.
- Exclusão de registros.
- Relatórios e visualização de dados.

### 4. Banco de dados

O projeto utiliza o MongoDB, um banco de dados NoSQL que armazena informações em documentos.

Foram utilizadas as coleções clientes e pedidos para organizar os dados da aplicação.

### 5. Segurança

O arquivo .env armazena a configuração de conexão com o banco de dados. Ele não deve ser compartilhado publicamente.

### 6. Conclusão

O desenvolvimento do E-Shop Brasil demonstra como tecnologias de banco de dados e programação podem contribuir para a organização e o gerenciamento das informações de uma empresa de comércio eletrônico.

### 11. Comparação entre bancos de dados relacionais e NoSQL

Os bancos de dados relacionais organizam as informações em tabelas, linhas e colunas, utilizando SQL para consultar e manipular os dados. São indicados para sistemas que precisam de estruturas bem definidas e relacionamentos entre informações.

Os bancos de dados NoSQL armazenam informações em formatos mais flexíveis, como documentos. Essa característica facilita o trabalho com grandes volumes de dados e informações que podem apresentar estruturas diferentes.

No projeto E-Shop Brasil, foi utilizado o MongoDB, que é um banco de dados NoSQL. Essa escolha permite armazenar os dados de clientes e pedidos em documentos, oferecendo flexibilidade para a aplicação.

### 12. Diferenças entre SQL e NoSQL

SQL é a linguagem utilizada para consultar e manipular dados em bancos relacionais. Ela permite realizar operações como inserir, consultar, atualizar e excluir informações.

NoSQL representa uma categoria de bancos de dados que utiliza modelos de armazenamento diferentes das tabelas tradicionais. O MongoDB, por exemplo, utiliza documentos no formato BSON, semelhante ao JSON.

No projeto E-Shop Brasil, o MongoDB é utilizado para armazenar e consultar os dados dos clientes e pedidos por meio da biblioteca PyMongo, que permite a comunicação entre Python e o banco de dados.

### 13. Tecnologias de Big Data: Hadoop e Spark

Big Data é utilizado para trabalhar com grandes volumes de dados, que podem ser gerados rapidamente e em diferentes formatos.

O Apache Hadoop permite armazenar e processar grandes quantidades de dados de forma distribuída.

O Apache Spark é uma tecnologia utilizada para processar grandes volumes de dados com rapidez, sendo muito útil para análises.

Em uma empresa de comércio eletrônico como a E-Shop Brasil, essas tecnologias podem ajudar a analisar compras, identificar preferências dos clientes, prever demandas e melhorar o controle de estoque.

### 14. Segurança da informação e LGPD

A segurança da informação é essencial para proteger os dados dos clientes e evitar acessos não autorizados.

A Lei Geral de Proteção de Dados (LGPD) estabelece regras para a coleta, o armazenamento e o uso de dados pessoais.

Na E-Shop Brasil, é importante proteger informações como nome, CPF, endereço e dados de contato dos clientes.

A empresa deve limitar o acesso aos dados, utilizar senhas seguras e evitar compartilhar informações pessoais sem autorização.

### 15. Personalização e melhoria da logística

A análise dos dados permite identificar os produtos mais procurados e as preferências dos clientes.

Com essas informações, a E-Shop Brasil pode recomendar produtos de acordo com o interesse de cada consumidor, melhorar a experiência de compra e oferecer promoções mais adequadas.

O uso de dados também pode ajudar a empresa a prever a demanda, controlar o estoque, organizar entregas e reduzir atrasos.
